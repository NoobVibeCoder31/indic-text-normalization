# Kannada data tables

Tab-separated, NFC-normalized, two or three columns. `pynini.string_file` cannot carry a
notes column, so provenance is recorded here per table. Digits in keys are Kannada
(U+0CE6 KANNADA DIGIT ZERO – U+0CEF KANNADA DIGIT NINE); ASCII input is mapped in code.

## Register and judgement calls (for the Kannada reviewer)

Formal written register was chosen for TN output. Items a native reviewer should confirm:

1. Tens and units fuse (`23 → ಇಪ್ಪತ್ತಮೂರು`, `21 → ಇಪ್ಪತ್ತೊಂದು`); every other group is spaced, the
   scale word in its linking form before a remainder: `105 → ನೂರಾ ಐದು`, `2024 → ಎರಡು ಸಾವಿರದ
   ಇಪ್ಪತ್ತನಾಲ್ಕು`, `1947 → ಸಾವಿರದ ಒಂಬೈನೂರಾ ನಲವತ್ತೇಳು`, `1,50,000 → ಒಂದು ಲಕ್ಷದ ಐವತ್ತು ಸಾವಿರ`,
   `2,50,00,000 → ಎರಡು ಕೋಟಿ ಐವತ್ತು ಲಕ್ಷ`. ITN also accepts the oblique hundreds (`ನೂರ ಐದು`) and
   spaced tens (`ಇಪ್ಪತ್ತು ಮೂರು`).
2. `1000 → ಸಾವಿರ` (bare) while one lakh and one crore take ಒಂದು (`1,00,000 → ಒಂದು ಲಕ್ಷ`); ITN
   accepts `ಒಂದು ಸಾವಿರ` too. A bare `ಲಕ್ಷ` or `ಕೋಟಿ` stays a word in ITN.
3. Negative sign `ಮೈನಸ್` (the loanword used in Kannada print); ITN also accepts `ಋಣ`.
   Decimal point `ದಶಾಂಶ` (ITN also accepts `ಪಾಯಿಂಟ್`).
4. A range takes the ablative on its lower bound: `10-20 → ಹತ್ತರಿಂದ ಇಪ್ಪತ್ತು`, `₹5-10 → ಐದರಿಂದ ಹತ್ತು
   ರೂಪಾಯಿ`, `₹5 - ₹10 → ಐದು ರೂಪಾಯಿಯಿಂದ ಹತ್ತು ರೂಪಾಯಿ`; ITN writes it as a suffix (`10ರಿಂದ 20`).
5. Fractions: `3/4 → ನಾಲ್ಕರಲ್ಲಿ ಮೂರು`, `2 3/4 → ಎರಡು ಮತ್ತು ನಾಲ್ಕರಲ್ಲಿ ಮೂರು`; ITN also accepts
   `ಮೂರು ಬೈ ನಾಲ್ಕು`. Vulgar signs read as everyday words: `½ → ಅರ್ಧ`, `¼ → ಕಾಲು`, `¾ → ಮುಕ್ಕಾಲು`,
   and fuse onto an integer (`1½ → ಒಂದೂವರೆ`, `2¼ → ಎರಡೂಕಾಲು`); ITN reads those back as decimals.
6. Time: `10:30 → ಹತ್ತು ಗಂಟೆ ಮೂವತ್ತು ನಿಮಿಷ`; a written AM/PM becomes the day part for that hour
   (`10:30 AM → ಬೆಳಿಗ್ಗೆ …`, `10:30 PM → ರಾತ್ರಿ …`, `2:00 PM → ಮಧ್ಯಾಹ್ನ …`, `6 PM → ಸಂಜೆ …`). `ಒಂದು
   ಗಂಟೆ` is as often the duration "one hour" as one o'clock, so ITN converts an hour only with
   a dative (`ಹತ್ತು ಗಂಟೆಗೆ → 10:00ಕ್ಕೆ`) or with minutes.
7. Money: invariant currency nouns (`₹50 → ಐವತ್ತು ರೂಪಾಯಿ`, `₹50.50 → ಐವತ್ತು ರೂಪಾಯಿ ಐವತ್ತು ಪೈಸೆ`);
   the dative of an -ಇ noun is -ಗೆ (`₹150ಕ್ಕೆ → … ರೂಪಾಯಿಗೆ`).
8. Measure: invariant units (`5 kg → ಐದು ಕಿಲೋಗ್ರಾಂ`); a suffix on a consonant-final loanword is
   set off with U+200C ZERO WIDTH NON-JOINER (`$5ಕ್ಕೆ → ಐದು ಡಾಲರ್‌ಗೆ`), the standard Kannada
   typography that keeps the suffix out of the final conjunct.
9. Case suffixes glued to a digit carry the -ರ augment as written and attach with sandhi:
   `2024ರಲ್ಲಿ → …ನಾಲ್ಕರಲ್ಲಿ`, `5ಕ್ಕೆ → ಐದಕ್ಕೆ`, `1000ರಲ್ಲಿ → ಸಾವಿರದಲ್ಲಿ`, `1000ಕ್ಕೆ → ಸಾವಿರಕ್ಕೆ`,
   `1,00,00,000ಕ್ಕೆ → ಒಂದು ಕೋಟಿಗೆ`, `10%ರಷ್ಟು → ಹತ್ತು ಪ್ರತಿಶತದಷ್ಟು`.
10. Ordinals: `5ನೇ → ಐದನೇ`, `1ನೇ → ಮೊದಲನೇ` (ITN also accepts ಒಂದನೇ), `10ನೆಯ → ಹತ್ತನೆಯ`.
11. Percent reads postposed, `5% → ಐದು ಪ್ರತಿಶತ`; the prefixed `ಶೇಕಡಾ ಐದು` is left alone by TN
    and inverted by ITN to `ಶೇಕಡಾ 5`.
12. A bare `ಒಂದು` stays a word in ITN (it is also the article "a"); it converts before a count
    noun or unit (`ಒಂದು ದಿನ → 1 ದಿನ`) and inside any longer number, date, time or amount.
13. `<` and `>` between digits stay as written: Kannada has no natural symbol-order reading.
