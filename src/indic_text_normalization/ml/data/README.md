# Malayalam data tables

Tab-separated, NFC-normalized, two or three columns. `pynini.string_file` cannot carry a
notes column, so provenance is recorded here per table. Digits in keys are Malayalam
(U+0D66 MALAYALAM DIGIT ZERO – U+0D6F MALAYALAM DIGIT NINE); ASCII input is mapped in
code. Chillu letters are the atomic code points (U+0D7A–U+0D7F); ITN folds the old
consonant + virama + U+200D ZERO WIDTH JOINER spellings onto them.

## Register and judgement calls (for the Malayalam reviewer)

Formal written register was chosen for TN output. Items a native reviewer should confirm:

1. Below a thousand a number is one word: tens and units fuse through the linking form
   (`23 → ഇരുപത്തിമൂന്ന്`, `21 → ഇരുപത്തിയൊന്ന്`), and a hundreds remainder is glued with a glide
   or a doubled consonant (`123 → നൂറ്റിയിരുപത്തിമൂന്ന്`, `110 → നൂറ്റിപ്പത്ത്`, `190 → നൂറ്റിത്തൊണ്ണൂറ്`).
   ITN also accepts the spaced spelling (`നൂറ്റി ഇരുപത്`).
2. Scale groups are spaced, the scale word taking its linking form before a remainder:
   `2024 → രണ്ടായിരത്തി ഇരുപത്തിനാല്`, `1947 → ആയിരത്തി തൊള്ളായിരത്തിനാൽപത്തിയേഴ്`,
   `1,50,000 → ഒരു ലക്ഷത്തി അൻപതിനായിരം`, `2,50,00,000 → രണ്ട് കോടി അൻപത് ലക്ഷം`. ITN also
   accepts the fully glued spelling (`രണ്ടായിരത്തിയിരുപത്തിനാല്`).
3. Thousands fuse with their multiplier (`5000 → അഞ്ചായിരം`, `3000 → മൂവായിരം`,
   `13000 → പതിമൂവായിരം`, `20000 → ഇരുപതിനായിരം`); ITN also accepts `പതിമൂന്നായിരം`.
4. One lakh and one crore take the counting ഒരു (`1,00,000 → ഒരു ലക്ഷം`, `1,00,00,000 → ഒരു കോടി`),
   while `1000 → ആയിരം` and `100 → നൂറ്` are bare; ITN accepts the bare `ലക്ഷം`/`കോടി` too.
5. Negative sign `മൈനസ്` (the loanword used in Malayalam print); ITN also accepts `ന്യൂന`, `ഋണ`.
   Decimal point `ദശാംശം` (ITN also accepts `പോയിന്റ്`).
6. Ranges read `പത്ത് മുതൽ ഇരുപത് വരെ`; ITN keeps the words (`10 മുതൽ 20 വരെ`).
7. Fractions: `3/4 → നാലിൽ മൂന്ന്`, `1/2 → രണ്ടിൽ ഒന്ന്`, `2 3/4 → രണ്ടും നാലിൽ മൂന്നും`; ITN also
   accepts `മൂന്ന് ബൈ നാല്`. Vulgar signs read as everyday words: `½ → അര`, `¼ → കാൽ`,
   `¾ → മുക്കാൽ`, and fuse onto an integer (`1½ → ഒന്നര`, `2¼ → രണ്ടേകാൽ`, `10¾ → പത്തേമുക്കാൽ`);
   ITN reads those back as decimals.
8. Time: `1:00 → ഒരു മണി`; `10:30 → പത്ത് മണി മുപ്പത് മിനിറ്റ്`; `10:01 → പത്ത് മണി ഒരു മിനിറ്റ്`;
   a written AM/PM becomes the day part for that hour (`10:30 AM → രാവിലെ …`,
   `10:30 PM → രാത്രി …`, `12:00 PM → ഉച്ചയ്ക്ക് …`, `6 PM → വൈകുന്നേരം …`). Bare `X മണിക്കൂർ` is a
   duration and is not converted by ITN.
9. Money: currency nouns are invariant (`₹50 → അൻപത് രൂപ`, `₹50.50 → അൻപത് രൂപ അൻപത് പൈസ`),
   `₹1 → ഒരു രൂപ`, `₹0.01 → ഒരു പൈസ`; `₹5K → അഞ്ചായിരം രൂപ` fuses like a cardinal.
10. Measure: units are invariant (`5 kg → അഞ്ച് കിലോഗ്രാം`, `1 kg → ഒരു കിലോഗ്രാം`); rates read
    `അറുപത് കിലോമീറ്റർ പ്രതി മണിക്കൂർ`.
11. Case suffixes glued to a digit attach with sandhi: `2024ൽ → …നാലിൽ`, `15ന് → പതിനഞ്ചിന്`,
    `1000ൽ → ആയിരത്തിൽ`, `5ഉം → അഞ്ചും`, `₹150ന് → …രൂപയ്ക്ക്`, `10:00ന് → പത്ത് മണിക്ക്`,
    `10%ൽ → പത്ത് ശതമാനത്തിൽ`. ITN writes the shortest spelling of each (`ൽ`, `ന്`, `ും`).
12. Ordinals: `5-ാം → അഞ്ചാം`, `1-ാം → ഒന്നാം` (regular), `10-ാമത്തെ → പത്താമത്തെ`,
    `1000-ാം → ആയിരാം`; `5ാം` and `5-ആം` are accepted too. ITN writes the hyphenated `5-ാം`.
13. Counting: `1 <count noun> → ഒരു <noun>` (`1 ദിവസം → ഒരു ദിവസം`) and `1 പേർ → ഒരാൾ`. ITN
    reverses `ഒരു` only before a unit word (`ഒരു കിലോഗ്രാം → 1 കിലോഗ്രാം`); before other nouns
    it is also the indefinite article, so `1 ദിവസം` does not round-trip.
14. A bare `ഒന്ന്` stays a word in ITN (it is as often the adverb "just": `ഒന്ന് നോക്കൂ`); it
    converts before a count noun or unit and inside any longer number, date, time or amount.
15. `<` and `>` between digits stay as written: Malayalam has no natural symbol-order
    reading, and speaking them out of order would misread the comparison.
